## מה הבעיה
המערכת מציגה "אינך משויך לארגון" למרות שלמשתמש המחובר יש רשומת חברות תקינה בארגון. בבדיקה כבר אושר שבמסד הנתונים קיימת חברות עבור `amoyal1976@gmail.com` בארגון "רוני".

## מה אתקן
1. **אחליף את מקור האמת של הארגון לצד שרת**
   - אעדכן את `useCurrentOrganization` כך שיפסיק להסתמך על join ישיר מהדפדפן לטבלאות הארגון.
   - במקום זאת הוא ישתמש בפונקציית השרת הקיימת `getCurrentOrganization`, שפועלת עם זהות המשתמש המחובר ומסננת לפי `userId` בשרת.

2. **אבטל את מצב ה־cache השגוי שיכול לנעול `null`**
   - אסיר או אשנה את מנגנון ה־localStorage של `current-organization-cache-v1`, כי כרגע הוא יכול לשמר מצב ישן של "אין ארגון" גם אחרי שיש חברות תקינה.
   - אדאג שרענון אחרי התחברות / שינוי session / עדכון ארגון יטען שוב את הארגון בצורה אמינה.

3. **אחזק את מצב הטעינה והמסך הריק**
   - בדף `/organization` לא אציג "לא משויך" לפני שהשליפה האמיתית הסתיימה.
   - אם יש שגיאה בשליפה, אציג מצב שגיאה ברור במקום מסר מטעה.

4. **אעדכן את כל המקומות שתלויים בארגון הנוכחי**
   - הכותרת העליונה
   - דף הארגון
   - רכיבי משנה שמשתמשים ב־`useCurrentOrganization`
   - כדי שכולם יקבלו את אותו מקור מידע עקבי.

5. **אאמת את התוצאה בפועל**
   - אבדוק שבמשתמש המחובר מופיע הארגון "רוני" במקום הודעת "לא משויך".
   - אוודא שגם אייקון הארגון/שם הארגון בכותרת עובדים נכון.

## פרטים טכניים
- קבצים עיקריים לבדיקה/שינוי:
  - `src/hooks/use-current-organization.ts`
  - `src/lib/organizations.functions.ts`
  - `src/routes/_authenticated/organization.tsx`
  - ייתכן שגם רכיבים נוספים שצורכים את ההוק
- כיוון התיקון: מעבר מ־browser query עם join ו־cache מקומי ל־server function כ־single source of truth.
- בנוסף, איישר את הגדרות ה־query/cache כדי שלא יישאר state שגוי אחרי התחברות או רענון.

## תוצאה צפויה
משתמש שמחובר ויש לו חברות בארגון יראה את הארגון שלו באופן עקבי, בלי הודעת "אינך משויך לארגון" שגויה.
