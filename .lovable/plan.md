
## מטרה
להחליף את מבנה ה"פרויקטים → מסמכים" במבנה ישיר: דף בית עם אריחים לכל סוג פלט, צ'אט ליצירה, ודף "המסמכים שלי" נפרד.

## דף הבית החדש (`/_authenticated/`)
רשת אריחים בסדר הזה (מעורבבים מסמכים + תרשימים לפי סדר זרימה טבעי בפרויקט):

1. מסמך ייזום
2. מסמך דרישות עסקי
3. תרשים Use Case
4. מסמך דרישות טכני
5. מסמך אפיון על
6. תרשים Flow Chart
7. תרשים Sequence
8. מסמך אפיון מפורט
9. תרשים State
10. תרשים Deployment

כל אריח: אייקון, שם, תיאור קצר, צבע. קליק → ניווט לצ'אט עם הסוג מוטמע.

## מסך הצ'אט (`/_authenticated/chat/$threadId`)
- שיחה אמיתית מרובת-הודעות, מאוחסנת ב-DB עם thread per "מסמך בהיווצרות".
- בנוי מ-AI Elements: `Conversation`, `Message`, `MessageResponse`, `PromptInput`, `Shimmer`.
- הודעת הסיסטם הראשונה נגזרת מסוג הפלט שנבחר (BRD/TRD/diagram וכו').
- האסיסטנט יכול להחזיר:
  - **מסמך** — JSON מובנה (אותה סכמה קיימת `SpecOutput`) שמוצג בעיצוב מסמך כרטיס + כפתור "פתח בעורך".
  - **תרשים** — בלוק קוד Mermaid מרונדר ב-`MermaidPreview` הקיים עם כפתורי העתק/הורד.
- לכל הודעה של AI שמייצרת מסמך/תרשים — שמירה אוטומטית ב-DB.
- היסטוריית שיחות בסיידבר ימני (רשימת threads עם תאריך ושם נושא).

## דף "המסמכים שלי" (`/_authenticated/documents`)
- רשימה שטוחה של כל המסמכים והתרשימים שנוצרו.
- חיפוש + פילטר לפי סוג (אריחים בראש כצ'יפים).
- כרטיס לכל פריט: שם, סוג, תאריך, prompt מקורי, כפתורי פתיחה/מחיקה.
