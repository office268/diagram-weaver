## עיצוב מחדש של מסך "המסמכים שלי"

### מה משתנה

**1. הסרת הכפתור "יצירת מסמך חדש"**
הכפתור הגדול בראש המסך יוסר. יצירת מסמך חדש כבר זמינה דרך טאב "בית" בניווט התחתון.

**2. הוספת מסמכים שהמשתמש העלה (uploaded_documents)**
המסך יציג גם קבצים שהמשתמש העלה (PDF/DOCX/וכו') לצד מסמכים ותרשימים שהוא יצר. נטען אותם דרך `listDocuments` מ-`src/lib/documents.functions.ts` ונשלב אותם באותה רשימה מאוחדת.

**3. סינון קומפקטי במקום צ׳יפים מרובי-שורות**
במקום 12 צ׳יפים שתופסים חצי מסך, נשתמש ב-**Sheet/Drawer** שנפתח מאייקון פילטר קטן (`SlidersHorizontal`). בתוך ה-Sheet:
- קטגוריות עליונות: "הכל" · "מסמכים שיצרתי" · "תרשימים" · "קבצים שהעליתי"
- מתחת — צ׳יפים של תתי-סוגים (לפי הקטגוריה שנבחרה)
- כפתור "נקה הכל" + מונה סינונים פעילים

על המסך הראשי יוצג רק badge עם מספר הסינונים הפעילים ליד כפתור הפילטר.

**4+5. שורת חיפוש אחת עם סינון ומיון צמודים**
שורה אחת קומפקטית (גובה ~44px) שמכילה משמאל לימין (RTL):
```
[🔍 חיפוש......................] [⇅ מיון] [⚙ פילטר •2]
```
- שדה חיפוש תופס את רוב הרוחב
- כפתור מיון פותח Dropdown: "חדש→ישן" · "ישן→חדש" · "לפי שם א׳-ת׳" · "לפי סוג"
- כפתור פילטר פותח את ה-Sheet מסעיף 3, עם נקודה/מונה אם פעיל

### פריסת המסך הסופית

```
┌─────────────────────────────────┐
│ המסמכים שלי                     │
│ כל המסמכים, התרשימים והקבצים    │
├─────────────────────────────────┤
│ [🔍 חיפוש...] [⇅ מיון] [⚙ סינון]│
├─────────────────────────────────┤
│ ▸ קטגוריה פעילה (אם יש): "הכל"  │
│                                 │
│ [כרטיס מסמך]                    │
│ [כרטיס תרשים]                   │
│ [כרטיס קובץ שהועלה]  ← אייקון   │
│ ...                             │  
└─────────────────────────────────┘
```

קבצים שהועלו יוצגו ככרטיסים באותו עיצוב, עם אייקון `Upload`/`FileUp` ותג קטן "הועלה", גודל קובץ, ותאריך. לחיצה תוביל לתצוגה/הורדה (נשתמש בנתיב הקיים אם יש; אחרת — תפריט הקשר עם הורדה ומחיקה בלבד).

### פרטים טכניים

- קובץ יחיד: `src/routes/_authenticated/documents.tsx`
- הוספת query שלישית: `listDocuments` → מיזוג לרשימת `Item` המאוחדת עם `category: "upload"` חדש
- state חדש: `sortBy: "date_desc" | "date_asc" | "name" | "type"`
- שימוש ב-shadcn `Sheet`, `DropdownMenu`, `Badge` (כולם כבר זמינים בפרויקט)
- שמירה על RTL וטוקני העיצוב הקיימים (`bg-card`, `border-border`, וכו׳)
- ללא שינויי backend או סכמה
